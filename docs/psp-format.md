# PS - 포맷 변환

PSP와 PS1(플레이스테이션 1) 이미지 포맷을 상호 변환하는 탭입니다. ISO, CSO, ZSO, CHD 네 가지 포맷을 서로 자유롭게 바꿀 수 있습니다.

**ZSO는 PSP뿐 아니라 PS1 쪽에서도 널리 쓰이는 포맷이라 이 탭에서 함께 다룹니다.**

파일마다 개별적으로 출력 포맷을 지정해서 변환할 수 있습니다.

## 화면 구성

- **파일 추가, 폴더 추가, 선택 삭제, 전체 삭제**
- **시작, 취소**

## 변환 가능 조합

원본을 넣으면 나머지 세 포맷 전부로 변환할 수 있습니다.

| 원본 | 선택 가능한 출력 |
|---|---|
| ISO | CSO, ZSO, CHD |
| CSO | ISO, ZSO, CHD |
| ZSO | ISO, CSO, CHD |
| CHD | ISO, CSO, ZSO |

- **CSO ↔ ZSO는 압축을 완전히 풀지 않고 바로 다른 압축 방식으로 바꿉니다.** (내부적으로 트랜스코딩 방식이라 ISO로 완전히 복원했다가 다시 압축하는 것보다 빠릅니다.)
- CSO와 ZSO는 같은 계열의 압축 포맷으로, ZSO는 LZ4 기반이라 CSO보다 압축/해제 속도가 더 빠른 대신 압축률은 다소 낮습니다.
- CHD는 chdman 압축을 사용하며, 압축 레벨은 설정 탭의 chdman 압축 설정을 따릅니다.

---

## 출력 파일

- 결과 파일은 원본과 같은 폴더에 생성되며, 확장자만 바뀐 이름으로 저장됩니다. 이미 같은 이름이 있으면 자동으로 겹치지 않는 이름으로 저장됩니다.
- **시작**을 다시 누르면, 이미 **완료**되었거나 **미지원**으로 표시된 항목은 건너뛰고 나머지만 처리합니다.
- 키파일이 필요 없습니다.

---

## 사용 예시

- CSO만 있는데 CHD로 바꾸고 싶을 때 사용하면 됩니다.
- CHD가 실기에서 인식되지 않을 때, 이 기능으로 다른 포맷으로 바꿔서 사용하면 됩니다.
- PS1 이미지를 ZSO로 압축해서 용량을 줄이고 싶을 때도 사용할 수 있습니다.
