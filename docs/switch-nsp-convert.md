# Switch - 새턴롬 NSP 변환

세가 새턴(SS) 게임 이미지를, 미리 준비된 새턴 에뮬레이터 포워더(베이스 NSP) 안에 넣어서 Switch에서 바로 실행 가능한 NSP 패키지로 만드는 탭입니다.

!!! danger "키파일 필수"
    이 기능은 Switch 키파일(`prod.keys`)이 반드시 있어야 동작합니다. 키파일 구하는 방법은 [실행 및 키파일 설정](installation.md)을 참고하세요.

## 화면 구성

1. **CUE 파일** — 변환할 새턴 게임의 원본 이미지 경로 (드래그 앤 드롭 가능). **CUE(+BIN) 뿐 아니라 CHD도 그대로 지정할 수 있습니다.** CHD를 넣으면 변환 과정에서 자동으로 압축이 해제됩니다.
2. **원본 NSP/NSZ 파일** — 베이스로 사용할 새턴 에뮬레이터 포워더 NSP 또는 NSZ 파일 (드래그 앤 드롭 가능) [다운로드](https://github.com/sinjunyoung/RomForge/releases/download/v1.3.0/base.nsz)
3. **작업 폴더**
4. **커버 이미지** — PNG, JPG, GIF, BMP, WEBP 지원. 드래그 앤 드롭하면 적용됩니다.
    - CUE/CHD를 지정하는 순간, 게임 ID를 기준으로 커버 이미지를 자동으로 찾아 다운로드해줍니다. 찾지 못해도 오류 없이 조용히 넘어가니, 자동으로 안 뜨면 직접 지정하면 됩니다.
5. **게임명** — 자동으로 채워지지만 직접 수정 가능
6. **배급사** — 상동
7. **게임 ID** — 읽기 전용. CUE/CHD 파일 안의 디스크 헤더를 직접 읽어 자동으로 채워집니다.
8. **버전** — 읽기 전용. 마찬가지로 디스크 헤더에서 자동으로 채워집니다.
9. **NSP 타이틀 ID** — 읽기 전용. **게임 ID 문자열을 CRC32로 계산해서 자동 생성된 값**이 표시됩니다. 게임마다 고유한 값이 나오도록 만드는 용도이며 직접 수정할 수 없습니다.
10. **설정**
    - **와이드 스크린** — 체크 시 와이드 스크린으로 출력
    - **사운드 볼륨** — 기본값 100%, 드롭다운으로 조절 (60/80/100/120%)
11. **작업 시작** — 변환 진행 (진행률, 속도, 경과 시간, 진행바 표시)

## 게임 정보는 어떻게 자동으로 채워지나

CUE(또는 CHD)를 지정하면, **디스크 첫 섹터의 헤더를 직접 읽어서** 게임 ID / 버전 / 게임명을 파싱합니다.
- CUE면 CUE가 가리키는 첫 번째 BIN 파일의 앞부분을, CHD면 첫 번째 헝크를 읽습니다.
- 헤더를 정상적으로 읽지 못하면(파일이 없거나, 새턴 디스크가 아니거나, 헤더 구조가 다르면) **게임명/게임ID/버전 세 필드가 전부 빈 값으로 초기화**됩니다. 자동 입력이 안 됐다면 파일 자체를 의심해보세요.
- 게임 ID 파싱에 성공하면 그 값으로 커버 이미지 자동 다운로드도 함께 시도됩니다.

**게임명은 자동으로 채워진 뒤에도 직접 수정할 수 있습니다.** 배급사, 커버 이미지도 마찬가지로 원하는 값으로 바꿔서 진행 가능합니다. (단, 게임 ID/버전/Title ID는 읽기 전용이라 디스크 자체에서 나온 값을 그대로 씁니다.)

---

## 지원하지 않는 타이틀

**게임 ID가 `T-1315G`(통곡 그리고...)인 타이틀은 명시적으로 차단되어 있습니다.** 이 타이틀을 넣으면 "통곡 그리고...는 현재 버전에서는 지원하지 않습니다" 오류가 뜨며 변환이 시작되지 않습니다.
(실기에서 실행이 안 되는 타이틀이기 때문에 제외)

## 변환 과정에서 실제로 일어나는 일

버튼 하나로 실행되지만, 내부적으로는 아래 단계를 순서대로 거칩니다.

1. **베이스 NSP 언팩** — 지정한 원본 NSP/NSZ를 작업 폴더에 언팩합니다.
2. **기존 새턴 이미지 제거** — 언팩된 데이터 안의 `romfs` 폴더에서, 포워더에 원래 들어있던 CUE/BIN(더미 새턴 이미지)을 찾아서 전부 삭제합니다.
3. **새 이미지로 교체** — CHD를 넣었다면 이 시점에 CD로 압축 해제해서, CUE라면 그대로 복사해서 같은 자리에 새로 채워 넣습니다.
4. **설정 파일 생성** — 같은 폴더에 `(CUE파일명)_Switch.ini` 파일을 새로 만들어 와이드 스크린/사운드 볼륨 설정 값을 기록합니다.
5. **타이틀 메타데이터 반영** — 언팩된 데이터의 언어 목록 중 **한국어 슬롯이 있으면 그걸, 없으면 첫 번째 언어**를 골라서 게임명/배급사/커버 이미지를 덮어씁니다.
6. **리팩** — 위에서 계산된 NSP 타이틀 ID로 새 NSP를 다시 빌드합니다.
7. **파일명 정리** — 결과 파일명을 `게임명 [TITLEID]_Saturn.nsp` 형식으로 자동으로 바꿔줍니다. 이미 같은 이름이 있으면 겹치지 않게 자동으로 새 이름을 만듭니다.
8. **임시 파일 정리** — 성공하든 실패하든, 작업 폴더의 언팩 임시 데이터(`unpacked`)는 항상 자동으로 삭제됩니다.

## 사용 방법

1. **CUE 파일**(1번)에 변환할 새턴 게임의 CUE 또는 CHD 파일을 지정합니다. 지정하는 즉시 게임 ID/버전/게임명이 자동으로 채워지고, 커버 이미지도 가능하면 자동으로 다운로드됩니다.
2. **원본 NSP/NSZ 파일**(2번)에 베이스로 사용할 NSP/NSZ 파일을 지정합니다. [다운로드](https://github.com/sinjunyoung/RomForge/releases/download/v1.3.0/base.nsz)
3. **작업 폴더**(3번)를 지정합니다.
4. 자동으로 채워진 게임명, 배급사, 커버 이미지를 확인하고 필요하면 수정합니다. 게임 ID/버전/NSP 타이틀 ID는 읽기 전용입니다.
5. 필요하면 와이드 스크린, 사운드 볼륨 옵션을 설정합니다.
6. **작업 시작**을 눌러 변환을 진행합니다.
