# 유틸리티 - 티스토리 다운로더

티스토리(또는 티스토리 기반) 블로그 게시글 URL을 넣으면, 그 글에 첨부된 다운로드 파일들을 자동으로 찾아내서 한꺼번에 받아주는 도구입니다. 분할 압축(7z.001, part1.rar 등)으로 나뉘어 올라온 파일도 알아서 병합·압축 해제까지 해줍니다.

## 화면 구성

- **티스토리 URL** — 한 줄에 하나씩, 여러 개 입력 가능 (`Ctrl+Enter`로 바로 분석 실행)
- **분석** — 입력한 URL들을 모두 읽어서 첨부파일 목록을 뽑아냅니다.
- **다운로드 위치** — 기본값은 실행 파일 폴더의 `TistoryDownloads`. 변경하면 다음에도 그 경로가 기억됩니다.
- **압축 자동 해제** — 체크하면 다운로드가 끝난 뒤 자동으로 압축을 풀어줍니다.
- **파일 목록** — 체크박스, 번호, 파일명, 용량, 상태, 진행률이 표시됩니다. 우클릭하면 **폴더 열기** 메뉴를 쓸 수 있습니다. 목록에서 항목을 선택하고 `Delete` 키를 누르거나 **선택 삭제**로 목록에서 뺄 수 있습니다(다운로드 자체를 취소하는 게 아니라, 받을 목록에서 제외하는 기능입니다).
- **다운로드** — 체크된 항목만 받습니다.

## 분석이 실제로 하는 일

**분석**을 누르면 입력한 각 URL의 HTML 페이지를 그대로 가져와서, 그 안에서 첨부파일로 보이는 링크를 찾아냅니다.

- 게시글 본문 영역(티스토리 에디터가 만드는 특정 영역) 안을 우선 찾고, 그게 없으면 페이지 전체에서 찾습니다.
- 다음 조건에 해당하는 링크를 첨부파일로 판단합니다.
    - 링크 주소에 `attachment`가 포함된 경우
    - `kakaocdn.net` 도메인의 링크 (확장자가 없어도 다운로드 링크로 인식)
    - `daum.net`/`daumcdn.net` 도메인이면서 `cfile`, `attach`, `original`, `tistoryfile` 등의 경로를 포함하거나 아래 확장자 목록에 해당하는 경우
    - 주소 자체가 아래 확장자 목록으로 끝나는 경우
- 인식 대상 확장자: `zip rar 7z alz egg gz tar` 등 압축 파일과, `iso bin cue img chd gdi` 등 디스크 이미지, `nsp xci nsz xcz 3ds cia cci` 등 콘솔 롬, `gba gbc gb nes sfc smc n64 z64 pce md sms` 등 레트로 롬 확장자
- **본문에 있는 이미지(png/jpg/jpeg/webp/gif)는 첨부파일이 아니라 삽입된 그림으로 보고 목록에서 자동으로 제외**합니다.
- 파일명과 용량은 가능하면 링크 주변 텍스트(예: `게임롬.zip (1.2 GB)` 같은 표기)에서 함께 읽어와 미리 보여줍니다. 못 읽으면 다운로드할 때 서버가 알려주는 파일명을 대신 씁니다.
- 여러 URL을 한 번에 넣고 분석하면 결과가 전부 같은 목록에 누적됩니다. 이미 목록에 있는 링크는 다시 분석해도 중복으로 추가되지 않습니다.
- URL 하나를 처리하는 데 실패해도(접속 불가, 페이지 구조가 다름 등) 나머지 URL은 계속 처리되고, 실패한 것만 로그에 남습니다.

## 다운로드

- 체크박스로 선택한 항목만 다운로드됩니다. **전체 선택은 목록 상단 체크박스로 한 번에 가능합니다.**
- **최대 5개까지 동시에 병렬로 다운로드**됩니다.
- 이미 "완료" 상태인 항목은 다시 눌러도 재다운로드하지 않고 건너뜁니다.
- 저장 파일명은 서버가 알려주는 이름을 우선 쓰고, 없으면 분석 단계에서 읽어온 이름을 씁니다. 이름이 너무 길거나(50자 초과) 확장자가 없으면 링크에서 유추한 이름으로 대체합니다.
- 파일명에 OS에서 못 쓰는 문자가 있으면 자동으로 `_`로 치환됩니다.
- 같은 이름의 파일이 이미 다운로드 위치에 있으면 `파일명 (1).확장자` 형식으로 자동으로 겹치지 않게 저장됩니다.
- 다운로드가 하나라도 성공하면, 작업이 다 끝난 뒤 다운로드 위치 폴더가 자동으로 열립니다.
- 취소하면 대기중/다운로드중이던 항목은 "취소" 상태로 표시되고, 이미 완료된 항목은 그대로 유지됩니다.

## 압축 자동 해제 (숨은 기능)

**압축 자동 해제**를 체크해두면, 다운로드가 전부 끝난 뒤 자동으로 압축을 풀어줍니다. 단순히 "압축파일이면 푼다"가 아니라, **여러 개로 쪼개진 분할 압축을 자동으로 인식해서 하나로 합쳐 풉니다.**

- 지원하는 압축 형식: ZIP, 7Z, RAR
- **분할 압축 인식 규칙**
    - 7Z 분할: `이름.7z.001`, `이름.7z.002` … 형식
    - RAR 분할: `이름.part1.rar`, `이름.part2.rar` … 형식
- 같은 이름 계열의 파일들을 자동으로 하나의 그룹으로 묶어서, **그중 1번 파트를 기준으로 압축을 해제**합니다. (일반 ZIP처럼 분할되지 않은 단일 압축파일은 그 파일 자체가 그룹이 됩니다.)
- **분할 파일 중 일부만 체크해서 받은 경우**(예: part1, part3만 받고 part2를 빠뜨린 경우), 압축을 풀지 않고 "볼륨 파일이 일부만 선택되어 있습니다"라며 건너뜁니다. 분할 압축은 반드시 모든 파트를 함께 받아야 합니다.
- 압축 해제 결과는 **원본 압축파일 이름으로 된 폴더**(다운로드 위치 안)에 풀리며, 완료되면 **원본 압축파일(분할 파트 전부)은 자동으로 삭제**됩니다. 폴더 이름이 이미 있으면 `폴더명 (1)`처럼 자동으로 새 이름이 붙습니다.
- 압축이 아닌 파일(롬 파일 등을 그냥 첨부한 경우)은 이 단계에서 손대지 않고 그대로 둡니다.

## 사용 방법

1. 다운로드하려는 게시글 주소를 **티스토리 URL**에 한 줄씩 붙여넣습니다(여러 글 동시에 가능).
2. **분석**을 누릅니다. 잠시 후 첨부파일 목록이 뜹니다.
3. 필요 없는 항목은 체크 해제하거나, 선택 후 삭제로 목록에서 뺍니다.
4. **다운로드 위치**를 확인하고, 분할 압축을 자동으로 풀고 싶다면 **압축 자동 해제**를 체크합니다.
5. **다운로드**를 눌러 진행합니다.
6. 완료되면 다운로드 위치 폴더가 자동으로 열립니다.

!!! tip "분할 압축은 전부 다 받아야 합니다"
    `xxx.7z.001`, `xxx.7z.002`처럼 여러 조각으로 나뉜 첨부파일은 반드시 **전부 체크**해서 함께 받아야 자동 압축해제가 됩니다. 하나라도 빠지면 압축해제가 건너뛰어집니다.
