# Switch - 병합

본편 + 업데이트 + DLC를 하나로 합치거나(병합), 이미 합쳐진 파일을 다시 본편/업데이트/DLC 각각의 파일로 되돌리는(분리) 탭입니다.

!!! danger "키파일 필수"
    이 기능은 Switch 키파일(`prod.keys`)이 반드시 있어야 동작합니다. 키파일 구하는 방법은 [실행 및 키파일 설정](installation.md)을 참고하세요.

## 화면 구성

1. **파일 리스트** — 병합 시에는 관련 파일들을 한꺼번에 넣으면 자동으로 그룹핑해서 병합합니다.
2. **파일 추가** — 여러 개 동시 지정 가능
3. **폴더 추가** — 폴더 내 전체 파일 추가
4. **선택 항목 제거**
5. **전체 항목 제거**
6. **출력 포맷** — **NSP, NSZ** 또는 **XCI, XCZ** 중 결과물의 계열을 선택합니다. 실제로 NSP로 나올지 NSZ로 나올지(또는 XCI/XCZ)는 아래 7번 압축 설정에 따라 자동으로 결정되며, 이 라디오 버튼에서는 큰 분류(NSP 계열 / XCI 계열)만 고릅니다. **원본이 NSP든 XCI든 상관없이, 병합·분리 결과물의 형식은 이 설정으로 결정됩니다.**
7. **압축 설정 탭으로 이동** — 압축 설정에서 압축 레벨에 따라 NSP, NSZ, XCI, XCZ가 결정됩니다. 무압축인 경우만 NSP, XCI, 압축 레벨을 설정한 경우에는 NSZ, XCZ로 나옵니다.
8. **도움말** — 도움말 웹페이지로 이동
9. **출력 폴더** — 최종 파일이 생성될 폴더
10. **병합 시작** — 파일 리스트를 하나로 합칩니다
11. **분리 시작** — 합쳐진 파일을 본편/업데이트/DLC로 되돌립니다
12. **로그**

## 병합: 자동 그룹핑이 실제로 하는 일

**여러 게임의 파일을 종류/게임 구분 없이 몽땅 한 리스트에 넣어도 됩니다.** 게임 A의 본편+업데이트+DLC, 게임 B의 본편+DLC를 한꺼번에 드래그해서 넣으면, **각 파일의 Title ID를 기준으로 자동으로 게임별 그룹**으로 나누고, **그룹마다 각각 독립적인 병합 결과 파일**을 만듭니다. 게임별로 리스트를 따로 만들어 여러 번 실행할 필요가 없습니다.

각 그룹 안에서는 다음 규칙으로 병합 대상이 정해집니다.

- **본편**: 그룹에 본편 파일이 있으면 그걸 사용합니다.
- **업데이트**: 그룹에 업데이트가 여러 버전 섞여 있어도 **버전이 가장 높은 것 하나만 자동으로 선택**되고, 나머지 오래된 버전은 결과물에서 제외됩니다. ([Switch - 리팩](switch-unpack-repack.md)의 "나중에 추가한 게 무조건 이긴다"는 규칙과 달리, **병합 탭은 실제로 버전을 비교해서 최신 것을 고릅니다.**)
- **DLC**: 전부 포함됩니다. 단, **같은 DLC(같은 Title ID)를 서로 다른 버전으로 중복해서 넣으면, 파일 단위가 아니라 내부 콘텐츠 파일 단위로 먼저 넣은 쪽이 우선권을 갖는 방식으로 섞입니다.** 예측하기 어려운 조합이 될 수 있으니, 같은 DLC는 하나의 버전만 넣는 걸 권장합니다.
- **본편 없이 업데이트나 DLC만 있어도** 병합이 진행됩니다. 이 경우 그룹 안에 있는 파일 중 하나(업데이트 우선, 그다음 DLC)를 기준으로 대표 메타데이터(제목 등)를 잡아 병합 결과를 만듭니다.
- 그룹에 유효한 콘텐츠가 하나도 없으면(예: 메타데이터를 못 읽는 경우) 해당 그룹은 조용히 건너뜁니다.

**최종적으로 오래된 업데이트에만 있던 파일이나, 최신 버전에서 이미 대체된 옛날 콘텐츠는 결과물에 아예 포함되지 않습니다.** 즉 여러 버전의 업데이트를 한꺼번에 넣어도 결과 파일 용량이 계속 불어나지 않고, 항상 최신 버전 기준으로 깔끔하게 정리됩니다.

## 분리: 병합 파일 안의 모든 콘텐츠가 각각 하나씩 나옵니다

분리는 병합의 정반대입니다. **병합된 파일 안에 들어있는 콘텐츠(본편/업데이트/DLC) 하나하나가 전부 별도의 파일로 분리되어 나옵니다.** 예를 들어 본편 + 업데이트 + DLC 3개가 합쳐진 파일 하나를 분리하면, 결과물은 본편 1개 + 업데이트 1개 + DLC 3개, 총 5개의 개별 파일이 됩니다.

- 리스트에 병합 파일을 여러 개 넣으면, 파일 순서대로 하나씩 처리되며 각 파일에서 나온 결과물이 전부 출력 폴더에 쌓입니다.
- 분리는 병합과 달리 **파일별로 독립적으로 처리**됩니다. 여러 파일을 한꺼번에 넣었을 때 그중 하나가 키 문제 등으로 실패해도, 나머지 파일의 분리는 계속 진행됩니다. (병합은 리스트에 키 인식 실패 파일이 하나라도 있으면 시작 자체가 막히는 것과 다른 점입니다.)

---

## 사용 예시

- **본편 + 업데이트 + DLC를 합칠 때**
- **통합 파일에서 본편 + 업데이트 + DLC를 분리할 때**
- **본편 + 업데이트(1.1) 통합 파일에 업데이트(1.2)를 합칠 때**: 기존 업데이트(1.1)는 제거되고 본편 + 업데이트(1.2)로 병합됩니다. 즉, 최신 업데이트만 남습니다.
- **여러 게임을 한 번에 정리할 때**: 게임 A, B, C의 본편/업데이트/DLC 파일을 종류 구분 없이 리스트에 몽땅 넣고 병합을 한 번만 실행하면, Title ID 기준으로 자동 분류되어 A, B, C 각각의 병합 결과 파일이 한 번에 만들어집니다.
