# 3DS - 포맷 변환

3DS용 파일을 3DS/CCI, CIA, ZCCI 상호간에 변환하는 탭입니다. [압축](compression.md) 탭의 3DS 부분과 달리, **CIA ↔ CCI 같은 순수 포맷 교환까지 한 곳에서** 처리합니다.

파일마다 개별적으로 출력 포맷을 지정해서 변환할 수 있습니다.

!!! danger "키셋 필수"
    이 기능은 3DS 키셋이 반드시 있어야 동작합니다. 키셋 구하는 방법은 [실행 및 키파일 설정](installation.md)을 참고하세요.

## 변환 가능 조합

| 원본 | 선택 가능한 출력 |
|---|---|
| 3DS | CIA, ZCCI |
| CCI | CIA, ZCCI |
| CIA | CCI, ZCCI |
| ZCCI | CCI (한 가지뿐) |

**ZCCI에서 CIA로 직접 갈 수는 없습니다.** ZCCI를 CIA로 만들고 싶다면, 먼저 CCI로 변환한 뒤 그 결과를 다시 CIA로 변환해야 합니다(2단계).

---

## certs.bin 필요 여부

**CIA로 변환하는 모든 조합(3DS/CCI → CIA)은 `certs.bin`이 필요합니다.** 없으면 해당 항목이 오류로 남고, 화면이 자동으로 certs.bin 추출 안내로 전환됩니다. 추출한 뒤 다시 시도하면 됩니다. 그 외 조합(→ZCCI, →CCI)은 certs.bin이 필요 없습니다.

---

## ZCCI 압축 레벨은 고정입니다

[압축](compression.md) 탭에서는 ZCCI 압축 레벨을 직접 설정할 수 있지만, **이 탭에서 ZCCI로 변환할 때는 압축 레벨이 18(최고 압축)로 고정**되어 있고 별도 설정 항목이 없습니다. 다른 레벨로 압축하고 싶다면 [압축](compression.md) 탭을 이용하세요.

---

## 재시작 / 배치 처리 규칙

- **시작**을 다시 누르면, 이미 **완료**되었거나 **미지원**으로 표시된 항목은 건너뛰고 나머지만 다시 처리합니다.
- 여러 파일을 한꺼번에 처리할 때, 그중 하나가 실패해도 나머지 파일은 계속 처리됩니다.
- 취소하면 그 시점에 아직 처리되지 않은(대기중/변환중) 항목들은 전부 "취소" 상태로 표시됩니다.

## 사용 예시

- 3DS(CCI) → CIA, ZCCI로 변환
- CIA → CCI, ZCCI로 변환
- ZCCI → CCI로 변환
