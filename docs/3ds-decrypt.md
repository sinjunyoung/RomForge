# 3DS - 복호화

3DS용 롬 파일을 복호화하는 탭입니다.

!!! danger "키셋 필수"
    이 기능은 3DS 키셋이 반드시 있어야 동작합니다. 키셋 구하는 방법은 [실행 및 키파일 설정](installation.md)을 참고하세요.

지원 확장자: `.3ds`, `.cci`, `.cia` (ZCCI는 대상이 아니므로, ZCCI라면 먼저 [압축](compression.md) 탭에서 CCI로 풀어야 합니다.)

## 화면 구성

1. **게임 파일 리스트**
2. **파일 추가** — 여러 개 동시 지정 가능
3. **폴더 추가**
4. **선택 삭제**
5. **전체 삭제**
6. **시작**
7. **취소**
8. **로그**

## 결과 파일

- **결과는 다른 탭들과 달리 별도의 `output` 폴더가 아니라, 원본 파일과 같은 폴더에 생성됩니다.**
- 파일명은 `원본파일명_dec.확장자` 형식입니다(확장자는 원본과 동일하게 유지). 이미 같은 이름이 있으면 자동으로 겹치지 않는 이름으로 저장됩니다.
- **certs.bin은 필요하지 않습니다.** (변환 탭에서 CIA를 새로 만들 때만 필요하며, 이미 있는 CIA/CCI/3DS를 복호화하는 이 작업은 인증서 서명 없이 내용만 읽어서 그대로 풀기 때문입니다.)
- 처리 중 실패하거나 취소하면, 그 시점까지 만들어지던 미완성 출력 파일은 자동으로 삭제됩니다.

## 재시작 규칙

**시작**을 다시 누르면, 이미 **완료**되었거나 **미지원**(이미 복호화된 파일)으로 표시된 항목은 건너뛰고 나머지만 처리합니다.

---

## 사용 예시

이미 복호화되어 있는 파일을 지정하면 자동으로 건너뛰고 진행됩니다. 즉, 복호화된 파일과 암호화된 파일이 섞여 있어도 상관없이 한꺼번에 넣고 돌리면, 암호화된 파일만 골라서 복호화합니다.
