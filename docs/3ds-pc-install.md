# 3DS - 설치 - 신규 게임 설치

3DS 실기로 직접 게임을 설치하면 매우 느리기 때문에, PC에서 SD 카드에 바로 게임을 설치하는 탭입니다.
(SD 카드 최고 성능으로 설치가 진행됩니다.)

!!! danger "키셋 + movable.sed 필수"
    이 기능은 3DS 키셋과 `movable.sed` 파일이 반드시 있어야 동작합니다.

    `movable.sed`는 SD 카드 루트 또는 `/gm9/out/` 하위에 복사해두면 자동으로 인식됩니다. 구하는 방법은 아래 화면 구성의 movable.sed 항목 툴팁을 참고하세요.

지원 입력 형식: `.3ds`, `.cci`, `.zcci`, `.cia` (ZCCI도 미리 풀 필요 없이 그대로 지정할 수 있습니다.)

## 화면 구성

1. **SD 카드**
2. **movable.sed** — 아이콘/텍스트에 마우스를 올리면 구하는 방법이 툴팁으로 표시됩니다:
    1. GodMode9 실행 (START + POWER)
    2. SYSNAND CTRNAND → private → movable.sed 선택
    3. 가장 하단의 Copy to 0:/gm9/out 실행
3. **movable.sed 선택** — 위 방법대로 SD 카드에 복사해두면 자동으로 인식되고, 위치가 다르면 이 버튼으로 직접 지정할 수 있습니다.
4. **게임 파일 리스트** — 각 게임 항목마다 **강제 언어** 드롭다운이 있어, 게임 안에 들어있는 사용 가능 언어 중 하나를 골라 강제로 그 언어로만 실행되게 고정할 수 있습니다. (기본값 "없음"이면 기존처럼 3DS 본체 설정을 따릅니다.)
5. **설치**
6. **취소**
7. **진행도**
8. **로그**

## 강제 언어 (숨은 기능)

일본 롬을 한글패치했는데 3DS 본체 언어 설정에 따라 다른 언어(예: 영어)로 뜨는 경우가 있습니다. 게임 리스트의 각 항목에서 **강제 언어**를 지정하면, 3DS 본체의 시스템 언어 설정과 무관하게 해당 게임만 지정한 언어로 고정해서 실행되도록 만들 수 있습니다.

- 선택 가능한 언어는 그 게임이 실제로 지원하는 언어 목록 안에서만 나타납니다.
- 제품 코드에서 지역을 판별할 수 없는 특수한 케이스는 강제 언어를 지정해도 적용되지 않고 건너뛰어지며, 로그에 안내가 남습니다.
- 내부적으로는 SD 카드에 `locale.txt`라는 설정 파일을 기록하는 방식으로 동작합니다.

## 이미 설치된 타이틀을 다시 설치하면

같은 Title ID를 가진 타이틀이 SD 카드에 이미 설치되어 있는 상태에서 설치를 시도하면, **"이미 설치되어 있습니다. 재설치하시겠습니까?"** 확인 창이 뜹니다. 확인하면 **기존에 설치되어 있던 데이터를 통째로 삭제한 뒤** 새로 설치합니다. 취소하면 그 타이틀만 건너뛰고 나머지 리스트는 계속 진행됩니다.

설치 도중 취소하면, 그 시점까지 만들어지고 있던 설치 데이터는 자동으로 삭제되어 SD 카드에 어중간한 상태로 남지 않습니다.

## 사용 예시

3DS 자체 설치 기능(FBI 등)은 매우 느려서, 게임을 여러 개 설치하려면 설치를 걸어놓고 오래 기다려야 합니다. 게다가 도중에 오류가 나면 파일을 다시 구해서 재시도해야 하는 번거로움도 있습니다.

이럴 때 이 기능을 사용하면 SD 카드 최대 속도로 게임을 설치할 수 있어 시간을 크게 절약할 수 있습니다.

!!! danger "설치 후 반드시 실행할 것"
    설치가 끝난 뒤, 3DS 실기에서 홈브류 런처로 `SD루트\3ds\custom-install-finalize.3dsx` 파일을 반드시 실행해야 3DS 홈 화면에 게임이 정상적으로 추가됩니다.

    게임 설치 후 이 파일이 SD 카드에 없으면 RomForge가 자동으로 복사해 줍니다.
