# WiiU - 리팩

Wii U 게임 파일을 관리하고 리팩하는 탭입니다. 본편/업데이트/DLC는 Title ID 카테고리(`00050000`=본편, `0005000e`=업데이트, `0005000c`=DLC) 기준으로 자동 분류됩니다.

지원 입력 형식: WUD, WUX, WUA, WUP 폴더, Loadiine 폴더

!!! danger "keys.txt는 원본이 WUD/WUX일 때만 필요합니다"
    3DS의 aes_keys.txt, Switch의 prod.keys와는 별개의, Wii U 전용 `keys.txt` 파일입니다.

    **WUA 파일이나 WUP/Loadiine 폴더만 사용한다면 keys.txt가 없어도 됩니다.** 목록에 WUD 또는 WUX 파일이 하나라도 있을 때만 keys.txt가 필요하며, 없으면 시작 자체가 막힙니다. 자세한 내용은 [실행 및 키파일 설정](installation.md)을 참고하세요.

## 화면 구성

- **파일 리스트** — 종류, 타이틀(아이콘/이름/버전), 한글패치 적용 여부, 경로가 표시됩니다.
    - 파일/폴더를 리스트 영역에 드래그 앤 드롭하면 추가됩니다.
    - 목록에서 우클릭하면 **폴더 열기**, **한글패치 취소**, **선택 삭제**, **전체 삭제** 메뉴를 사용할 수 있습니다.
    - 각 항목의 **한글패치** 칸을 클릭하면 해당 타이틀에 적용할 한글패치를 지정할 수 있습니다. **폴더** 또는 **압축파일(zip/7z)** 로 지정 가능합니다. (Switch 리팩 탭과 달리, 압축파일에 비밀번호를 지정하는 기능은 없습니다.)
- **선택 삭제 / 모두 삭제** 버튼 (목록 오른쪽)
- **출력 포맷** — WUA(에뮬레이터용) 또는 WUP(실기용) 중 선택
- **작업 폴더**
- **언팩** / **리팩 (폴더 기반)** / **언팩 + 리팩 (Full)** 버튼
- **진행률 표시줄** — 진행률, 속도, 경과 시간

## 목록에 추가할 때 실제로 일어나는 일

- **본편과 업데이트는 종류당 최대 1개만 유지됩니다.** 새로 본편(또는 업데이트) 파일을 추가하면, 버전을 비교하지 않고 **무조건 새로 추가한 쪽이 이전 것을 대체**합니다("기존 OO을(를) 새 항목으로 교체합니다" 로그가 남습니다). 여러 버전을 갖고 있다면 원하는 버전을 마지막에 추가하세요.
- **DLC는 계속 쌓입니다.**
- **폴더를 드롭할 때는 WUP 폴더나 Loadiine(내부에 `code`/`content`/`meta` 폴더가 모두 있는) 구조여야만 인식됩니다.** 그 외의 일반 폴더(예: 임의로 언팩해둔 폴더)를 드롭하면 "WUP 폴더나 로드라인 폴더가 아니라서 자동 추가할 수 없습니다"라는 오류와 함께 거부되며, 이런 경우 아래 언팩 → 한글패치 지정 → 리빌드 흐름을 이용해야 합니다.
- WUD/WUX 파일을 추가하려는데 keys.txt가 없으면, 그 시점에 바로 "keys.txt가 exe 폴더에 없습니다" 오류가 뜨고 추가되지 않습니다.

## 언팩 / 리팩 / 언팩+리팩(Full) 동작 차이

| 버튼 | 동작 |
|---|---|
| **언팩** | 작업 폴더 아래 `unpacked` 폴더에 언팩까지만 진행합니다. |
| **리팩(폴더 기반)** | 이전에 **언팩**으로 만들어둔 `unpacked` 폴더를 다시 스캔해서 그 결과로 리빌드합니다. 이때 **화면의 파일 리스트에 이미 지정해뒀던 한글패치가 있다면, Title ID와 버전이 일치하는 항목에 한해 자동으로 그대로 이어붙습니다.** `unpacked` 폴더가 없으면 "언팩된 데이터가 없습니다" 오류로 실행되지 않습니다. |
| **언팩 + 리팩(Full)** | 언팩부터 리팩까지 한 번에 처리합니다. |

- **언팩**을 실행할 때 작업 폴더에 이미 `unpacked` 폴더가 남아있으면 "기존 언팩 데이터를 삭제하고 새로 진행할까요?"라고 먼저 확인합니다.
- **언팩** 도중 실패하거나 취소하면, 만들어지고 있던 `unpacked` 폴더가 자동으로 삭제됩니다. (리팩/Full은 이 정리 대상이 아닙니다.)
- 결과 파일은 작업 폴더에 그대로 생성되고, 완료되면 작업 폴더가 자동으로 열립니다.

## 사용 방법

1. 게임 파일이나 폴더를 리스트에 드래그 앤 드롭합니다. 본편/업데이트/DLC는 자동으로 분류됩니다.
2. 필요하면 각 타이틀의 한글패치를 지정합니다.
3. **출력 포맷**에서 WUA(에뮬레이터) 또는 WUP(실기)를 선택합니다.
4. **작업 폴더**를 지정합니다.
5. 상황에 맞게 **언팩**, **리팩(폴더 기반)**, 또는 **언팩 + 리팩(Full)** 중 하나를 실행합니다.
