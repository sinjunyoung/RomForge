# Switch - 포맷 변환

Switch용 파일 하나를 NSP, NSZ, XCI, XCZ **네 가지 포맷으로** 자유롭게 바꿀 수 있는 탭입니다. [압축](compression.md) 탭이 "압축 ↔ 압축 해제" 한 방향만 다루는 것과 달리, 이 탭은 **NSP ↔ XCI 같은 순수 포맷 교환과 압축/해제를 한 번에 다 지원**합니다.

!!! danger "키파일 필수"
    이 기능은 Switch 키파일(`prod.keys`)이 반드시 있어야 동작합니다. 키파일 구하는 방법은 [실행 및 키파일 설정](installation.md)을 참고하세요.

파일마다 개별적으로 출력 포맷을 지정해서 변환할 수 있습니다.

## 변환 가능 조합

원본 확장자를 기준으로, **나머지 세 포맷 전부로 변환할 수 있습니다.** 목록에 추가하면 아래 표의 "기본 선택"으로 자동 지정되며, 드롭다운에서 다른 포맷으로 바꿀 수 있습니다.

| 원본 | 선택 가능한 출력 | 기본 선택 |
|---|---|---|
| NSP | XCI, NSZ, XCZ | XCI |
| XCI | NSP, NSZ, XCZ | NSP |
| NSZ | NSP, XCI, XCZ | NSP |
| XCZ | XCI, NSP, NSZ | XCI |

즉 압축 상태(NSP/XCI ↔ 압축 상태(NSZ/XCZ)를 바꾸는 것뿐 아니라, **압축된 상태 그대로 카트리지용 ↔ 카드용 형식을 바꾸는 것도(NSZ↔XCZ) 중간에 풀었다 다시 압축할 필요 없이 한 번에** 처리됩니다.

## NSZ, XCZ 변환 시 영향받는 설정

이 설정은 **[Switch - 리팩](switch-unpack-repack.md), [Switch - 병합](switch-merge.md) 탭과 값을 공유합니다.** 어느 탭에서 바꾸든 다른 Switch 관련 탭에도 그대로 적용됩니다.

**압축 레벨**

zstd 계열은 압축 레벨을 0~22까지 지정할 수 있지만, RomForge에서는 3~18까지만 지정 가능합니다. 19 이상은 속도가 급격히 느려지는 데 비해 압축률 차이는 미미해서 제외했습니다.

**압축 모드**

- **블록**: 탐색 가능, 고속 — 에뮬레이터에서 사용 가능
- **블록리스**: 탐색 불가, 고압축 (블록 대비 압축률 차이는 크지 않음)

**압축 무결성 검증**

압축 후 원본과 데이터가 동일한지 BLAKE3 해시로 검증합니다. Switch는 현세대 기기라 포맷이 바뀔 가능성이 있으므로 검증을 권장합니다. 검증 없이 원본을 삭제했다가 복구가 불가능해질 수 있습니다.

## 재시작 규칙

**시작**을 다시 누르면, 이미 **완료**되었거나 **미지원**으로 표시된 항목은 건너뛰고, **실패**하거나 **취소**된 항목만 다시 시도합니다. 목록을 다시 정리할 필요 없이 시작 버튼만 다시 누르면 됩니다.

---

## 사용 예시

- NSZ를 받았는데 XCZ로 바꾸고 싶을 때 사용합니다. (다른 확장자는 안 되고 모든 파일을 XCZ로 통일하고 싶은 경우에 유용합니다.)
- NSZ를 XCI로 곧바로 바꾸고 싶을 때도, 압축 해제 후 XCI 변환까지 한 번에 처리되므로 이 탭 하나로 끝낼 수 있습니다.
